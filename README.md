## FAQ

### What exactly is XCutors?

XCutors is a curated Windows desktop package that bundles multiple popular Roblox script executors together with a universal loader (xcutorsLoader) for convenient management and script execution.

### Which executors are included in the package?

XCutors ships with Volt, Synapse Z, Potassium, and Wave — four widely used executors — plus the xcutorsLoader universal launcher that ties them all together.

### Is XCutors free to use?

Yes. XCutors and the xcutorsLoader are completely free. Note that some individual executors bundled within may have their own licensing or access models.

### Which versions of Windows are supported?

XCutors supports Windows 10 and Windows 11 (64-bit). Older versions of Windows are not officially supported and may encounter compatibility issues.

### How do I update XCutors when a new version is released?

Simply download the latest release ZIP from the GitHub Releases page and replace the files in your existing installation folder. The built-in update checker will also notify you of new versions.

### Can I add my own custom executors to xcutorsLoader?

Yes. xcutorsLoader supports adding third-party executors by placing them in the designated executors folder and editing the config.json file with the appropriate entry.

### Does XCutors collect any personal data?

No. XCutors operates entirely offline on your local machine. No telemetry, analytics, or personal data is collected or transmitted.

### Why do I need to run xcutorsLoader as Administrator?

Running as Administrator ensures the loader and its bundled executors have the necessary system permissions to inject scripts into the Roblox client process.
